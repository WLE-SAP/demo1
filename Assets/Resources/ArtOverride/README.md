# 图片素材上传文件夹（美术替换 · 一物一图）

把图片直接拖进这个文件夹，游戏启动时会自动用它替换「这一个物件」的程序化图元。

**规则：文件夹里没有图片 → 用代码画的图元（默认状态）；有图片 → 图片优先。一张图只管一个 key。**

> 这里是快捷说明；**完整格式要求与像素建议见根目录 [`README.md`](../../../README.md)**。

---

## 1. 最重要的一条：一物一图

以前是「一张 `disc.png` 同时换掉树冠 + 村民的头 + 羊 + 路灯……」，现在**每个物件一个 key**：

- `house_roof.png` 只换屋顶，**不会**连带换掉木箱、村民身子、农田；
- 想换哪样就放哪样，其余的保持程序化美术，互不影响；
- 没放的、没写对名字的，都会在 Console 里如实报出来。

## 2. 文件命名规则

文件名（不含扩展名）= key。比较时**忽略大小写、下划线、短横线和空格**，
所以 `HouseRoof.png`、`house_roof.png`、`house-roof.png` 是同一个 key。

同一个 key 放了多张图 → **只用先载入的那张**，其余的会在 Console 里被点名。

## 4. key 一览（开始界面）

| key | 是什么 | 推荐像素 | 说明 |
| --- | --- | --- | --- |
| `menu_background` | 整屏背景 | 1920 × 1080 或任意 16:9 | **整张铺满屏幕**（不重复平铺），画一张完整的背景图即可 |
| `menu_panel` | 面板底板（主面板 / 设置 / 地图选择） | 128 × 128 | 九宫格圆角矩形；**会被面板颜色染色**（白图 = 米白面板） |
| `menu_button` | **所有按钮**共用的底图 | 128 × 128 | 九宫格圆角矩形；**会被各按钮自己的颜色染色**（开始=绿、继续=蓝…） |

> 不放这三个 key 时，开始界面**自己用代码画**：背景是纵向渐变（深绿 → 稍亮的绿），
> 面板与按钮是白色圆角矩形九宫格，再乘上各自的颜色 —— 所以永远不会有空白或报错。

## 5. 颜色：什么时候图片会被染色

| 情况 | 行为 |
| --- | --- |
| 绝大多数 key | **图片原样显示**（颜色刷成白色，程序化配色被顶掉） |
| `villager_body` / `villager_head` | 保留染色：衣服颜色 = 职业、肤色随机 —— 颜色本身是「这个村民是谁」的信息 |
| `house_window` / `lamp_head` / `forge` | 保留染色：白天 / 夜里颜色不同（夜里会亮起来） |
| `highlight` / `highlight_rect` / `garden_flower` / `stall_awning` | 保留染色：底衬的黄 / 橙、花的 5 色、篷布的 5 色 |
| `menu_panel` / `menu_button` | 保留染色：颜色是「哪个按钮干什么」的标识 |

**想完全控制外观**：给上面这些 key 就画成白色 / 浅灰的形状图（染色后就是你要的颜色），
或者干脆不改这些物件（它们本身就有配色）。

## 6. 尺寸、锚点与九宫格（导入时自动算好）

导入时 `ArtOverridePostprocessor` 会把图片设成 **Sprite**，并做两件事：

1. 按 **该 key 对应的原素材在世界里的宽度** 反推 `Pixels Per Unit`
   → **不管你是 64px 还是 1024px，替换后占的位置都和原来一样大**；
2. 九宫格 key 会把**边框**按原素材的圆角比例自动放大到你的图上
   → 你的图四角不会被拉伸变形（例：`menu_button` 64px 原图圆角 20px，你交 128px 的图 → 边框自动设成 40px）。

- **锚点固定为图片中心** → 内容画在正中间，四周留透明边距；
- 比例按**宽度**对齐，高度按图片自身长宽比等比缩放；
- 想手动改大小：改该图片 Import Settings 里的 `Pixels Per Unit`（越大画面里越小）。
  自动配置只在**首次导入**时执行，之后你改的值会保留；
- 文件名没对上 key 时按通用值导入：**64 像素 = 1 世界单位**，并会在 Console 里被点名。

## 7. 生效范围与限制

- 只影响 `BugScene` 与 `MainMenu`；小虫的尾巴是 LineRenderer 画的曲线，**没有 key 换不掉**
  （要调它改 `Bug/Body` 上 WormBody 的 `width` / `spacing` / 摆动幅度）。
- 世界是无限流式的：区块边走边生成 / 回收，但同类物件用的是同一个 key 的图，替换是全局一致的。
- 场景里手工摆的三个精灵（`Bug/Head`、`MoveMarker`、`Environment/Ground`）通过 `ArtSlot` 组件标 key；
  其余物件在生成时自己套用。

## 8. 怎么看有没有生效

运行游戏后看 Console：

- `[ArtOverride] 从 Resources/ArtOverride 载入 N 张图片。` → 图片被读进来了
- `[ArtOverride] 图片 N 张，场景精灵替换了 M 个（村庄里的物件在生成时已各自替换）。` → 生效
- `没对上 key（名字写错了？）：xxx` → 文件名没对上，照上面的表改名
- `key xxx 放了多张图片，只用先载入的 …` → 同一个 key 放多了，删到只剩一张
- `[ArtOverride] 开始界面：背景 用图片 / 程序绘制渐变，面板 x/y 用图片，按钮 x/y 用图片。` → 开始界面
- `[ArtOverride] Resources/ArtOverride 里没有图片，使用程序化美术。` → 文件夹是空的（默认状态）

## 9. 恢复默认

删掉这个文件夹里的图片即可回到程序化美术，不需要改任何代码。
