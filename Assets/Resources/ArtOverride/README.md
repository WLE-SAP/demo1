# 图片素材上传文件夹（美术替换）

把图片直接拖进这个文件夹，游戏启动时会自动用它们替换原本程序化画的精灵。

**规则：文件夹里没有图片 → 游戏完全使用原有的程序化美术（默认状态）；有图片 → 图片优先。**

---

## 1. 文件命名规则

文件名（不含扩展名）= 要替换的素材名。下面两种写法都行（比较时忽略大小写、下划线、短横线）：

| 想替换的东西 | 友好文件名 | 等价的原始素材名 | 会影响到 |
| --- | --- | --- | --- |
| 小虫的头 | `bug_head.png` | `S_BugHead.png` | 小虫的头 |
| 点击移动的标记 | `crosshair.png` / `marker.png` | `S_Crosshair.png` | 点击目标点的十字标记 |
| 地面草地 | `ground.png` / `grass.png` | `T_Grass.png` | 地面（**平铺**，跟着小虫无限延伸） |
| 道路 | `road.png` | `T_Road.png` | 每个区块中心的十字路 + 广场（**平铺**） |
| 矩形色块 | `rect.png` | `S_Rect.png` | **房屋屋顶/墙体/门窗 + 木箱 + 村民的身子 + 农田的垄 + 牧场围栏** |
| 圆角矩形 | `roundrect.png` | `S_RoundRect.png` | 木箱的高亮底衬 |
| 圆形 | `disc.png` | `S_Disc.png` | 树冠、村民的头、水井、羊、花、路灯头、**地洞的洞口和小石头**、各种高亮底衬 |
| 果子 | `berry.png` | `S_FoodBerry.png` | 地上的果子 |
| 叶子 | `leaf.png` | `S_FoodLeaf.png` | 地上的叶子 |

> 木箱、房屋、村民共用 `S_Rect`，所以没有单独的 `crate.png`。
> `S_Bush` / `S_Rock` / `S_Eye` / `S_Crate` / `S_Fence` 这些素材文件虽然还在 `Assets/Sprites` 里，
> 但当前游戏已经没用到（地图没有边界了，栅栏已删除），放同名图片不会生效——
> 运行时会出现在「未匹配到素材」列表里提醒你。

## 2. 图片资源规范（请按这个格式提供）

### 2.1 基本格式

| 项目 | 要求 |
| --- | --- |
| 文件格式 | **.png**（24 或 32 位）。不要用 .jpg（没有透明通道）、不要放 .psd/.ai 源文件 |
| 透明通道 | 有、且**背景必须真透明**（不要用白底/绿幕底，否则会实心盖住底下的东西） |
| alpha 类型 | 直通 alpha（Straight），**不要预乘 alpha**；Unity 会自动处理 |
| 色彩空间 | sRGB，8 位/通道；不要给素材做 HDR / 线性空间转换 |
| 单张尺寸 | 任意分辨率都行，最大 **2048×2048**；单文件建议 < 2 MB |
| 文件命名 | 只用英文小写、数字、下划线（如 `bug_head.png`）；同一个 key 只放 **一张** 图 |
| 建议像素密度 | **64 像素 = 1 世界单位**（和项目自带素材保持一致，最好直接按这个画） |

### 2.2 每个素材的建议像素与特殊要求

| key | 原始素材 | 占地的世界尺寸 | 推荐像素 | 特殊要求 |
| --- | --- | --- | --- | --- |
| `bug_head` | S_BugHead(128×128) | 1 × 1 | 128 × 128 | 朝向默认**朝右**（+X | 是头的正前方） |
| `crosshair` | S_Crosshair | 1 × 1 | 64 × 64 | 十字/圆圈居中，线条细一点更清楚 |
| `ground` | T_Grass(256×256) | 4 × 4 | 256 × 256 | **必须无缝平铺**（左右、上下接得上）；用 2 的幂尺寸 |
| `road` | T_Road(256×256) | 4 × 4 | 256 × 256 | **必须无缝平铺**；道路走向按图内纹理，四边要能接上 |
| `rect` | S_Rect(64×64, 九宫格边 20) | 1 × 1 | 64 × 64 | 纯色/细纹矩形；会被九宫格拉伸，四角保留 20px 不变形区 |
| `roundrect` | S_RoundRect(64×64, 九宫格边 20) | 1 × 1 | 64 × 64 | 圆角矩形，圆角半径 ≈ 20px，会拉伸 |
| `disc` | S_Disc(64×64) | 1 × 1 | 64 × 64 | 正圆，铺满画布（不要留边距），会按不同大小缩放 |
| `berry` | S_FoodBerry | 1 × 1 | 64 × 64 | 内容居中、留 1–2px 透明边 |
| `leaf` | S_FoodLeaf | 1 × 1 | 64 × 64 | 内容居中、留 1–2px 透明边 |

### 2.3 尺寸和位置怎么算（不用手改导入设置）

导入时 `ArtOverridePostprocessor` 会自动做两件事：

1. 把图片设成 **Sprite** 类型（FullRect、无 mipmap、Clamp、Alpha Is Transparency）；
2. 按 **被替换素材在世界里的宽度** 反推 `Pixels Per Unit`。

也就是说：**不管图片是 64px 还是 1024px，替换后占的位置都和原素材一样大**，不用手动调。

- 锚点固定为**图片中心**，所以请把内容画在画布正中间、四周留出透明边距；
- 比例按**宽度**对齐，高度按图片自身比例等比缩放（非正方形图会让物件变高/变矮）；
- 想手动控制大小：改该图片 Import Settings 里的 `Pixels Per Unit`（数值越大，画面里越小）。
  自动配置只在图片首次导入时执行，之后你改的值会保留；
- 文件名没匹配到任何素材时，按通用值导入：**64 像素 = 1 世界单位**。

## 3. 生效范围与限制

- 覆盖是「按素材名」**全场景替换**：例如 `disc.png` 会把树冠、村民的头、羊、花、路灯头一起换掉。
- 小虫的尾巴是 LineRenderer 画的等宽黑色曲线，**不支持换成图片**。
  想调它：`Bug/Body` 上 WormBody 的 `width`（粗细）、`spacing`（节距）、摆动幅度；
  颜色在 `Bug/Body` 的 LineRenderer → Materials 里。
- 世界是无限流式的：区块会随小虫移动不断生成 / 回收，但所有区块里的同类素材用的是同一套
  替换图，所以替换是全局一致的。
- 只影响 `BugScene`；开始界面 `MainMenu` 的 UI 不受影响。

## 4. 怎么看有没有生效

运行游戏后看 Console：

- `[ArtOverride] 图片 N 张，替换了 M 个精灵。` → 生效
- `未匹配到素材（名字写错了？）：xxx` → 文件名没对上，照上面的表格改名
- `[ArtOverride] Resources/ArtOverride 里没有图片，使用程序化美术。` → 文件夹是空的

## 5. 恢复默认

删掉这个文件夹里的图片即可回到程序化美术，不需要改任何代码。
