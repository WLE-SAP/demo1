# 音频素材上传文件夹

把音频文件直接拖进这个文件夹，游戏会在对应事件上自动播放；**不放文件 = 全程静音（默认状态）**。

**文件名（不含扩展名）= key**，比较时忽略大小写 / 下划线 / 短横线 / 空格，并自动忽略
`sfx_` / `se_` / `sound_` / `audio_` 前缀（`eat.wav`、`SFX_Eat.wav`、`se-eat.ogg` 都算 `eat`）。

| 文件名 | 什么时候响 | 循环 | 建议时长 |
| --- | --- | --- | --- |
| `eat` | 吃掉东西（果子/树叶/木箱/树/村民） | 否 | 0.2–0.4 s |
| `grow` | 长大一级（紧跟在 eat 后面） | 否 | 0.6–1.5 s |
| `pickup` / `drop` | F 键拾取 / 放下 | 否 | 0.1–0.3 s |
| `step` | 走路脚步（按距离触发） | 否 | 0.05–0.15 s |
| `ui_click` | 开始界面点按钮 | 否 | ≤ 0.15 s |
| `bgm` | 游戏场景 `BugScene` | **是** | 30–120 s |
| `bgm_menu` | 开始界面 `MainMenu` | **是** | 30–120 s |

格式要求（摘要，完整版见项目根目录 `README.md`）：

- 音效 **.wav**（单声道）、BGM **.ogg**；44100 / 48000 Hz，16 位；
- 峰值不超过 **−1 dBFS**（绝不削波）；音效之间电平对齐到 **−6 ~ −3 dBFS**；
- 音效不要静音头尾；**BGM 必须无缝循环、不要自带淡入淡出**；
- 一个 key 只放**一个**文件；不要用中文或空格命名。

放进来的文件**不需要手改 Import Settings**：BGM 自动按流式载入、音效自动按预载导入。

运行后看 Console：

- `[AudioOverride] 音频 N 个，可用 key：…` → 生效；
- `……没对上 key（名字写错了？）：xxx` → 文件名没对上，照上表改名；
- `[AudioOverride] Resources/AudioOverride 里没有音频，静音运行。` → 文件夹是空的。

想恢复默认：把这个文件夹里的音频删掉即可。
