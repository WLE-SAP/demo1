## 10:49 ~ 11:21 · 项目基线：确认为 2D、定操作方式、备好中文 UI

**目标**：确定这个项目到底按 2D 还是 3D 做，并把「玩家怎么操作」和「中文能不能显示」这两件基础事定死。

**做了什么**
- 确认项目是 **2D 工程**（`ProjectSettings/EditorSettings.asset` → `m_DefaultBehaviorMode = 1`，Packages 已装 `com.unity.feature.2d`）；
  实现一律走 SpriteRenderer + Physics2D + 正交相机，**不用** 3D 图元 + CharacterController 方案。
- 操作方式定为**点击式**：鼠标左键点地图移动、空格进食、F 交互拾取/放下；**取消 WASD 键盘持续控制**（用户明确要求）。
- 美术走「简化实现」路线（用户确认）：接受程序化生成的精灵/图元与 LineRenderer 曲线代替精细美术
  ——例：小虫 = 黑色圆点头 + 一条等宽黑色曲线身体。
- 打通 TextMeshPro 中文：导入 TMP Essential Resources，加入 `Assets/Codely/Fonts/NotoSansSC-Regular SDF.asset`
  （动态图集 + 多图集）到 TMP 全局 fallback 列表。

**涉及文件**
- 修改：`ProjectSettings/EditorSettings.asset`（确认 2D 模式，未改值）
- 新增：`Assets/Codely/Fonts/NotoSansSC-Regular SDF.asset`

**验证**

- 未系统留档。

**遗留问题 / 下一步**

## 11:21 ~ 13:34 · 小虫移动手感、尺寸基准、视野与村民美术

**目标**：让小虫「动起来像活的」，并定下尺寸/视野基准。

**做了什么**
- 修掉两个必踩的移动坑（详见 [`Spec.md`](Spec.md) 红线清单）：
  - `Rigidbody2D` 静止后会进入睡眠，睡眠后写 `velocity` / `Rotate` 全部无效 → 设 `sleepMode = NeverSleep`；
  - `freezeRotation = true` 时 `MoveRotation()` 不生效 → 小虫旋转改用 `rb.SetRotation()`。
- `SimpleHUD` 从 IMGUI（`OnGUI`/`GUI.Label`）改写成 **uGUI + TextMeshPro**
  （IMGUI 不走 TMP 全局 fallback，中文会变方块）；Canvas 用 `ScaleWithScreenSize` 1920×1080。
- 小虫整体尺寸缩到原尺寸 **0.5×**（头 `0.14`、尾宽 `0.08`、节距 `0.0335`、碰撞半径 `0.07`、标记 0.2；
  互动距离 `eatRadius 1.3` / `interactRange 2.6` / `holdDistance 0.95` 有意不同步缩小，保留宽松手感）。
- 相机正交视野 `orthographicSize` 2.8 → **8.4**（可见约 16.8 × 29.9 世界单位）。
- 村民美术简化为「一个圆当头（`S_Disc`）+ 一个长方形当身子（`S_Rect`）」，**整体恒不旋转**，
  只用 `Visual` 的 X 缩放做左右翻转；翻转方向取 `FixedUpdate` 里的**目标方向**而不是 `rb.velocity`
  （被挤/撞时物理求解器会改 velocity，导致朝向乱翻）。

**涉及文件**
- 修改：`Assets/Scripts/BugController.cs`、`WormBody.cs`、`SimpleHUD.cs`、`Villager.cs`
- 修改：`BugScene.scene`（相机 `orthographicSize`、小虫/村民尺寸与结构）
- 修改：`Assets/Scripts/GameInput.cs`（交互键统一）

**验证**
- 运行时：`transform.up` / `transform.right` 确实随朝向变化（不只看脚本内部变量）；移动、旋转、翻转方向正常。
- 视觉：当时用 Game View 人工确认；`analyze_multimedia` 当天有额度报错（402），不能作为唯一依据。

**遗留问题 / 下一步**
- 尺寸参数分散在多个脚本/场景字段里，后续调整要成套改（见 Spec 的「尺寸成套项」）。

## 14:20 · 地洞 / 地道、村民视野与职业反应、排序层整理

**目标**：给玩家一个「躲藏」玩法，并让村民「看得见」小虫。

**做了什么**
- **地面贴图遮挡问题**：农田/花坛/牧场草地这类整块贴图按自身中心 Y 排序会盖住站在其上的角色 →
  全部移入新建的 **Ground 排序层**用固定次序排（草地 −900 → 道路 −885 → 农田 −870/−860/−850 →
  牧场 −845 → 花坛 −840/−835/−830）；只有 `YSort` 对象（小虫/村民/木箱）才用世界 Y 排序。
- **地洞 `Burrow`**：每区块 0~2 个，其中 `tunnelChance 0.45` 是地道；`VillageWorld.PairTunnels()`
  在已加载区块里把 24~110 距离的两头地道配对（另一头销毁时解链后重配）。
  E 键钻洞（隐去头/尾、关碰撞、村民看不见）/ 出洞（不受冷却限制）/ 走地道瞬移（`FollowCamera.Snap` 立刻跟上）。

- `MainMenu` 标题改为「What a Bug？」，副标题「好大一条虫！」。

## 14:53 · 玩法扩充 10 项（体力/成长/悬浮窗/冲刺/交互统一）

**目标**：让小虫有「活下去」的压力与「长大变强」的成长曲线。

**做了什么**
1. `VillageWorld` 每 0.5s 检查可见框（`viewHalfSize 13×7.5`）内村民数，少于 `minVillagersInView 2` 就在玩家附近补人
   （挂当前区块下、每区块上限 `maxExtraPerChunk 4`）。
2. HUD 三块面板不再重叠：`SimpleHUD.LayoutPanels()` 运行时按上一块实际高度往下排。
3. `BugVitality` 体力条：满 100、每秒掉 0.8；掉光**饿死** → 存档体力回 60% → 1.8s 后回主菜单（不掉档）。
4. `HiddenValue`「不显示的数值」：物品分量（决定饱食度）、村民体魄（决定追逐耐心与移速）。
5. 特殊食物「神奇果实」+ `BugGrowth` 成长 3 级（体型 ×1.35 / 速度 +12% / 捕食半径 +28% / 体力上限 +25 每级）。
6. `EncounterWindow` 右下角悬浮窗：靠近物品/村民弹介绍（`EntityInfo` 提供文本），走开 1.2s 淡出。
7. 捕食改整圈（`eatAngle 360`、`eatRadius 0.7`，只要靠近头部）。
8. Shift 冲刺（11 速、0.22s 持续、0.9s 冷却）。
9. 交互键统一 F（`GameInput.Interact`，E 已废弃；优先级：出洞 → 放下 → 钻洞/传送 → 拾取）。
10. 主菜单标题 What a Bug？/ 好大一个虫！。
