# 2026-09-23 · 开发日志

## 08:27 ~ 08:40 · 四项新玩法：地图类型、食物分级、目击者反应、音量设置

**目标**：一局游戏有「换个地图玩」的选择，也让「长大」真正有意义（能吃的东西变多）。

**做了什么**
- **地图类型** `MapKind{荒野, 农村, 城市}`（`MapProfiles.cs`）只覆盖**密度参数**，不改生成逻辑：
  荒野 `hamletChance 0.15` / 每村 0~1 人 / 关掉「保证视野里有村民」；农村 `0.65` / 2~4；城市 `1.0` / 6~9（`minInView 5`、`maxExtra 6`、`freeze 22`）。
  同一颗种子 9 区块实测村民数 **6 / 26 / 74**。由 `VillageWorld.ApplyMapKind()` 在建区块前套用。
  地图记在 `PlayerPrefs game.mapKind` + 存档；开始界面新增「选择地图」面板。
- **食物分级**：玩家看到的等级口径是 `BugGrowth.DisplayLevel`（= 内部 `level + 1`），
  门槛常量 `CrateLevel 2` / `TreeLevel 3` / `VillagerLevel 4`，靠 `Edible.requiredLevel` + `BugEat.CanEat` 过滤；
  木箱/树/村民都挂了 `Edible`（村民饱食度 45）。
- **目击者**：吃村民时 `Villager.ReportEaten()` 只把**现场目击者**（≤ `witnessRadius 11` 且 `CanSeeBug`，或离受害者 ≤ `witnessCloseRadius 4.5`）
  标记 `fearsBug = true`：永久把职业反应覆盖成 `Flee`、视野 ×1.25、躲避距离与时长 ×1.35；**不存档**。
- **音量**：`GameSettings`（`AudioListener.volume` + `PlayerPrefs game.volume`，`RuntimeInitializeOnLoadMethod` 启动自动套用）。
  开始界面新增「游戏设置」面板（分辨率 ◀▶ / 屏幕模式 / 音量 − +）。

**涉及文件**
- 新增：`Assets/Scripts/MapProfiles.cs`、`GameSettings.cs`
- 修改：`Assets/Scripts/VillageWorld.cs`、`VillageGenerator.cs`、`Villager.cs`、`BugEat.cs`、`Edible.cs`、`BugGrowth.cs`、`MainMenu.cs`、`SaveSystem.cs`（存档升 v2）
- 修改：`MainMenu.scene`（`SettingsPanel` / `MapPanel` 用编辑器脚本搭进去）

**验证**
- 运行时：同一种子切换三张地图，统计 9 区块村民数 6 / 26 / 74；
  等级不够时 `BugEat.FindTarget()` 跳过目标、HUD 提示「长到 3 级才吃得下这个」；
  吃掉村民后只有现场目击者改为躲避。
- 视觉：`analyze_multimedia` 已恢复可用（成功分析 `record_game_view` 录屏），用它核对过 HUD 中文文案与面板布局。

**遗留问题 / 下一步**
- 坑已进红线：**存档 `version` 必须显式判断**（`JsonUtility.FromJson` 会跑字段初始化器，不能用「字段缺省」当哨兵）。
- 工程仍无任何 `AudioSource`，音量设置听不出效果 → 见 09:00 那节。

## 09:00 ~ 09:10 · 根 README 重写为「资源交付说明」+ 接入音频覆盖系统

**目标**：给美术/音效同学一份可执行的素材交接文档（重点讲**图片与音频的提供格式**），
并把音频这条路真正打通，让文档里的规范不是空文。

**做了什么**
- **重写根 `README.md`**：改成资源交付说明 —— 图片 9 个 key 的格式/像素/九宫格/平铺要求、
  音频的格式/命名/响度/无缝循环要求、播放行为表、交付清单、排错表、实现位置。
  （原「游戏玩法与代码结构」内容随之移出 README，脚本职责改由各脚本头部中文注释承载。）
- **新增音频覆盖系统**（与图片 `ArtOverride` 对称，全部运行时引导，**不改任何场景/Prefab**）：
  - `AudioOverride.cs`：key 别名表 + `Resources/AudioOverride` 载入；key 常量在 `AudioKeys`
    （`eat` / `grow` / `pickup` / `drop` / `step` / `ui_click` / `bgm` / `bgm_menu`）；
    匹配忽略大小写/下划线/短横线/空格，并自动忽略 `sfx_` / `se_` / `sound_` / `audio_` 前缀；
  - `AudioOverridePlayer.cs`：`RuntimeInitializeOnLoadMethod(AfterSceneLoad)` 自动创建**跨场景常驻**播放器；
    音效 `PlayOneShot`；`sceneLoaded` 切 BGM（`BugScene` → `bgm`，其余 → `bgm_menu`，循环）；
    `musicVolume 0.7` / `sfxVolume 1`；
  - `BugFootsteps.cs`：场景加载后自动挂到 `BugController`，按**走过的距离**（`strideLength 0.6`）触发 `step`，
    最短间隔 0.09s、±8% 随机音高，躲地洞/静止不出声；
  - `Assets/Scripts/Editor/AudioOverridePostprocessor.cs`：放进目录的音频自动配置导入设置
    （BGM 流式载入 / 音效预载+解压到内存），不用手改 Import Settings。
- **音效触发点**：`BugEat`（吃掉 → `eat`；长大 → `grow`）、`DragController`（拾取/放下）、
  `MainMenu.WireButtons`（改成统一 `Bind` 辅助方法，点任意按钮播 `ui_click`）。
- 新增 `Assets/Resources/AudioOverride/README.md`（目录内简短说明，与 `ArtOverride/README.md` 同风格）。

**涉及文件**
- 新增：`Assets/Scripts/AudioOverride.cs`、`AudioOverridePlayer.cs`、`BugFootsteps.cs`、
  `Assets/Scripts/Editor/AudioOverridePostprocessor.cs`、`Assets/Resources/AudioOverride/README.md`
- 重写：`README.md`
