**过程中发现并修掉的问题（都是测试逼出来的）**
1. **一次停电会被算两次混乱**：电线断时它自己和射程内的机器各广播一次 `PowerChanged` →
   改成电线统一广播一次、机器静默断电（`SetPower(on, announce)`）。
2. **啃断孤零零的电线「什么都没发生」**：射程内没有机器时原来不广播任何事件 →
   改成电线自己一定广播「这一片断电了」，任务与混乱值才有反馈。
3. **警觉值的「谁看得见小虫」原来每帧全扫村民**（二三十个）→ 降频到 0.2 秒一次。
4. **测试踩到的坑（记下来免得再踩）**：验证「饿死」时 `BugVitality` 会在 7 秒后切到主菜单场景，

**过程中发现并修掉的四个真问题**
1. **`pump` / `alarm` 漏了门控**（测试逼出来的）：README 一直承诺「电线 / 泵 / 油桶 / 警报器这四样只在村庄刷」，
   但代码里只有 `wire` / `oilbarrel` 写了 `hamletOnly`，`pump` / `alarm` 只写了 `Fixed(...)` →
   **野外也会刷抽水泵**（而野外没有电线，那台泵永远漏不了，只是一块废铁）。已补 `InSettlements(农村, 城市)`。
2. **平铺素材被导成 Clamp**：`ArtOverridePostprocessor` 一律设 `TextureWrapMode.Clamp`，
   而 `ground` / `road` 是用 Tiled 画的 —— 玩家真交了平铺图，接缝处会被拉伸出一道糊边。

3. **路型抽签用了错误的种子**：一开始写的是 `seed`（Inspector 里的默认值）而不是 `worldSeed`，

4. **城市因为「大公寓塞不进碎地块」而盖得太稀**：宽路面 + 广场 + 设施把 32×32 切成碎地块，

## 22:25 ~ 22:55 · 修「路面呈条纹状、接不上」：直路瓦片改 Sliced + 横纵瓦片用反了 + 路尽头对齐

**目标**：用户反馈「路面生成逻辑要更新，使路径能够首尾相接，而不是呈现条纹状」。

**做了什么（三个 bug，叠在同一段路上）**
- **① `drawMode = Tiled` 用错了**（「条纹状」的正主）：`Tiled` 是按**精灵自己的自然尺寸**重复的，
  而瓦片图 128px ÷ 64PPU = **2 世界单位**，路面却要 12 宽 → 一条路面上并排重复 **6 次**，
  画出来就是 6 条细条纹。改成 **`Sliced`**（沿路拉伸）：瓦片里的路是**通长一条**，
  拉伸只改长度、不改路宽，两端照样和路口瓦片、区块边界严丝合缝（拉伸量实测 0.82~1.18，看不出来）。
- **② 横向臂 / 纵向臂的瓦片用反了**：左右臂应当用「横向路瓦片」`road_straight_h`（`path2`）、
  上下臂用 `road_straight_v`（`path1`），原来正好写反 —— 表现是**每段路中央横着一条挡板**
  （路被画成垂直于行进方向），再叠上①的重复，整条路就完全不成形。
- **③ 路尽头瓦片的「路尖」不在瓦片正中**：交付的这套在 0.70 处（新增字段 `roadHeadTipRatio`，
  实测 `roadhead-right` 路在左半边、路尖在 70%），原来把**瓦片中心**摆在区块边界上 →
  路会多伸出去 0.2×tile ≈ 2.4 米。改成**让路尖正好落在边界上**（中心摆在 `radius − 0.2×tile`）。

**怎么定位的（这个办法以后继续用）**：Play 里把非 `Ground` 排序层的渲染器全关掉 →
