**过程中发现并修掉的问题（都是测试逼出来的）**
1. **一次停电会被算两次混乱**：电线断时它自己和射程内的机器各广播一次 `PowerChanged` →
   改成电线统一广播一次、机器静默断电（`SetPower(on, announce)`）。
2. **啃断孤零零的电线「什么都没发生」**：射程内没有机器时原来不广播任何事件 →
   改成电线自己一定广播「这一片断电了」，任务与混乱值才有反馈。
3. **警觉值的「谁看得见小虫」原来每帧全扫村民**（二三十个）→ 降频到 0.2 秒一次。
4. **测试踩到的坑（记下来免得再踩）**：验证「饿死」时 `BugVitality` 会在 7 秒后切到主菜单场景，

**过程中发现并修掉的四个真问题**
1. **`pump` / `alarm` 漏了门控**（测试逼出来的）：README 一直承诺「电线 / 泵 / 油桶 / 警报器这四样只在村庄刷」，
   但代码里只有 `wire` / `oilbarrel` 写了 `hamletOnly`，`pump` / `alarm` 只写了 `Fixed(...)` →
   **野外也会刷抽水泵**（而野外没有电线，那台泵永远漏不了，只是一块废铁）。已补 `InSettlements(农村, 城市)`。
2. **平铺素材被导成 Clamp**：`ArtOverridePostprocessor` 一律设 `TextureWrapMode.Clamp`，
   而 `ground` / `road` 是用 Tiled 画的 —— 玩家真交了平铺图，接缝处会被拉伸出一道糊边。
   现在 `Slot` 多一个 `tiling` 标记（地面 / 路面共 6 个 key），导入时设 Repeat。
3. **路型抽签用了错误的种子**：一开始写的是 `seed`（Inspector 里的默认值）而不是 `worldSeed`，
   结果**所有世界长出同一套路网**。改成 `chunkWorldSeed`。
4. **城市因为「大公寓塞不进碎地块」而盖得太稀**：宽路面 + 广场 + 设施把 32×32 切成碎地块，
   公寓需要约 5.8×6.8 的空地，于是名义 11~16 栋实测只有 6.5 栋。对策：`BuildHouses` 里
   **连着失败 60 次就把房型降小一号**（公寓 → 排屋 → 两层小楼 → 农舍），实测提到约 8 栋。
   （这是**已知的数量差**：名义 11~16 是历史数值，实际受地块物理限制；已写进 Spec §4.12 与 `WorldBiome` 注释。）

**遗留问题 / 下一步**
- 除了「取消选地图 + 两套体系」这一批，计划里的 **⑤B 更多房型 / ⑤C 更多可交互物品 / ⑤D 更多因果链**
  大多被这一批吸收了（房型 6 种、新物品 6 种都做了），**还没做的**是：
  ⑤D 的**因果链**（风车磨坊 / 蜂群 / 火灾 / 敲钟集会）—— 钟楼现在只会自己敲钟报时，没有「敲钟 → 全村聚集」那条链。
- **城市的房子数量**达不到名义值（见上）；想更密就调小 `BuildHouses` 里 `IsFree(area, 1.0f)` 的余量，
  或者给城市单独提 `houseMin/Max`。**手感需要实机确认**。
- **沙漠里的产出偏少**：仙人掌果 34 权重 + 通用品，而草原 / 森林有 3~4 种食物可选；
  沙漠的仙人掌果实测每区块 4~8 个，够吃但选择少 —— 这是刻意的（沙漠就该荒），**但需要实机确认**。
- **草原区块没有自己的地面 key**（用的还是无限草地的 `ground`）：好处是玩家交 `ground.png` 立刻看得见，
  代价是**草原没法单独换一张和背景不同的地面**。要改就在 `WorldBiome.GroundKey` 里给 `Grassland` 也返回一个 key。
- 地貌区域尺度（`NatureRegion 3` / `SettlementRegion 4` = 96 / 128 世界单位）是拍的：
  **走多久才会换一种地貌、城市稀不稀**，需要实机走一圈才知道合不合适。
- 沙漠城市 / 森林城市这类「交叉组合」是自动长出来的（沙漠里也会有城市），**观感需要看一眼**
  （沙地上盖石铺路的城市街道是否协调）。
